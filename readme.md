=======

Project made by me as a kid. I used my own python discord bot template for this.
This repository server as the bot and the server, basically a part of a larger project with a web frontend.

Packages
------------

- FastAPI
- Disnake (Discord BOT API for python)
- Prisma  (I've used an unofficial python wrapper)

------------

Bot's (+ website) features: 

1. Website controls / settings.
2. Utility commands
3. Server economy (users getting money for messages and voice-chat time) 
4. Custom shop (managed per-server by admins)
